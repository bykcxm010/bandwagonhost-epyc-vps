## AMD EPYC 对 VPS 用户意味着什么？

2. **确认产品系列和节点可选范围。** 搬瓦工的不同 VPS 系列不能简单视为同一套餐换个机房。要在下单页核对配置、机房和迁移选项。
3. **按工作负载选内存、存储和流量。** 小型网站和测试环境与数据库、多个容器或高访问量服务的需求差别很大。不要只为 CPU 名称买明显过大的方案。
4. **需要时做自己的测试。** 对延迟敏感的服务，可以在退款政策允许的范围内检查实际访问、网络路由和负载表现。公开的 CPU 名称不能替代真实工作负载测试。

## 怎样判断目标方案是否适合你？

如果你搜这个词是为了找一台 EPYC VPS，可以按下面的顺序核对，避免买到“看起来差不多、实际不是同一类”的方案。

### 先看机房是否是已公告的 EPYC 部署点

目前官网公告明确提及洛杉矶 DC9、纽约 USNY_6/USNY_8 和香港 HK3/HK8。下单时要确认所选产品确实能部署到目标机房。官网新闻公告说明硬件部署情况，但不保证每个套餐都可选每个位置。

### 再看价格对应的计费周期

基础 KVM 方案里既有年付、半年付，也有月付。只比较标价容易误判：例如 $49.99 是年付价格，$19.99 则是月付价格，不能把二者直接当成同一周期的费用来比。查看结账页时，也要核实所选周期和最终应付金额。

### 最后按用途核对资源

- **个人站点、开发测试**：重点看内存是否够用、每月流量是否充足，入门配置可能已经足够。
- **多个服务或数据库**：优先评估内存和存储空间，别只追求更多 vCPU。
- **面向特定地区的业务**：先选离用户近、网络路径合适的机房，再核对线路和目标用户的实际访问情况。
- **CPU 密集型任务**：确认套餐的 CPU 描述和部署机房，并在能实际测试的条件下观察工作负载表现。仅凭“AMD EPYC”几个字，无法推导具体任务一定快多少。

## 购买前容易忽略的几点

**AMD EPYC 是机房硬件信息，不等于每个套餐都使用 EPYC。** 官网首页的基础 KVM 套餐标注为 Intel Xeon；EPYC 则在特定机房的硬件公告中出现。两组信息对应的产品和页面语境不同，比较时要分清。

**NVMe RAID-10 不代表所有存储性能指标都已公开。** 公告确认了洛杉矶 DC9、纽约节点和香港节点的 NVMe RAID-10 存储，但没有在公告中提供每个套餐的 IOPS、持续读写速度或 CPU 型号。这些指标若未出现在具体方案页面，就不应当作已知条件。

**自管理意味着服务器运维由用户负责。** 搬瓦工提供 KiwiVM 管理功能和系统重装等操作，但这与代为维护应用、配置数据库或排查网站代码问题不是一回事。购买前应确认自己能处理操作系统更新、服务配置和备份恢复等任务。

**退款与保障条款要看适用范围。** 官网 VPS 页面列有 99.9% uptime guarantee 和 30-day refund policy。下单前仍应查看服务条款，确认具体订单适用的条件和限制；不要把保障说明理解为对单次业务表现的保证。

## 常见问题

### 搬瓦工所有 VPS 都使用 AMD EPYC 吗？

不能这样说。官网首页展示的基础 KVM 方案标注了 Intel Xeon；EPYC 是官方在特定机房公告中确认的服务器部署信息。购买时应核对套餐系列和机房，而不是只看品牌搜索结果。

### 搬瓦工 EPYC VPS 有哪些已确认地点？

官方公告确认了洛杉矶 DC9（USCA_9）、纽约 USNY_6 与 USNY_8，以及香港 HK3 与 HK8。不同地点可购买的方案和迁移选项可能不同，页面库存也可能调整。

### 能从产品页面直接确认具体 EPYC 型号吗？

上述公告没有列出具体型号、频率或每台 VPS 的 CPU 分配细节。如果这些参数对你的应用很关键，应以购买页面或客服对具体节点的确认作为依据，不能从处理器品牌自行推断。

### 选 EPYC 还是选线路？

看用途。计算任务对 CPU 更敏感；面向某地区用户提供服务时，机房位置和网络路径可能更重要。先确定服务对象与主要瓶颈，再对照可选节点、资源配置和价格，通常比单独追逐某个 CPU 品牌更有效。
